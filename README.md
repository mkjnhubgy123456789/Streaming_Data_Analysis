# YouTube Streaming Data Analysis

A machine learning and analytics project focused on Hip-Hop streaming data analysis, playlist extraction, engagement analytics, and hit-song prediction modeling.

## Features
- YouTube streaming analytics
- Playlist extraction automation
- Data cleaning and preprocessing
- Visualization dashboards
- Excel VBA integration
- Machine learning analysis
- Streaming engagement analytics

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Excel VBA
- YouTube API

## Project Structure
- data/ → raw and processed datasets
- scripts/ → analytics and API scripts
- docs/ → reports and presentations
- config/ → API configuration files
